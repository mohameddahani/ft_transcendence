## Member Statistics API

### Admin Platform — Member Stats

**GET**

`/api/admins/members/stats`

This endpoint is used in the **Admin Platform** and returns statistics about all members belonging to the admin's club.

The frontend should use this endpoint directly for dashboard/statistics cards. There is no need to fetch all member records and calculate the values on the frontend.

**Response example:**

```json id="glhuxs"
{
  "activeCount": 245,
  "pendingCount": 42,
  "bannedCount": 12,
  "expiredCount": 39,
  "total": 338
}
```

### Response Fields

- `activeCount`: Number of members whose account status is `ACTIVE`.
- `pendingCount`: Number of members whose account status is `PENDING`.
- `bannedCount`: Number of members whose account status is `BANNED`.
- `expiredCount`: Number of members who have at least one `EXPIRED` membership and currently have no `ACTIVE` membership.
- `total`: Total number of members belonging to the club.

### Important Note About `expiredCount`

`expiredCount` is based on the member's memberships, not their account status.

For example:

```text id="7ovllk"
Member A
Memberships:
- EXPIRED
- EXPIRED

→ counted in expiredCount ✅
```

```text id="exk2li"
Member B
Memberships:
- EXPIRED
- ACTIVE

→ not counted in expiredCount ❌
```

A member with an active membership is not considered expired even if they have older expired memberships.

### Frontend Usage

Example:

```ts id="e4wrl8"
const response = await fetch('/api/admins/members/stats');

const stats = await response.json();

console.log(stats.total);
console.log(stats.activeCount);
console.log(stats.pendingCount);
console.log(stats.bannedCount);
console.log(stats.expiredCount);
```

The dashboard can use:

```ts id="6vqxj1"
stats.total
stats.activeCount
stats.pendingCount
stats.bannedCount
stats.expiredCount
```

Example cards:

```text id="8zvurb"
Total Members   → stats.total
Active Members  → stats.activeCount
Pending Members → stats.pendingCount
Banned Members  → stats.bannedCount
Expired Members → stats.expiredCount
```

### Important

`activeCount`, `pendingCount`, and `bannedCount` come from the member's **account status**.

`expiredCount` comes from the member's **membership status**.

Because these represent different concepts, `expiredCount` should not be added to the other account-status counts to calculate `total`.

Always use:

```ts id="99qkr5"
stats.total
```

for the total number of members.
